# Art assets for Merope-C

Images in this folder are web-optimized copies for review and personal-site use. The full-size originals remain in the uploaded archives and have not been modified.

- `Comms.zip` was compared against `all art.zip` using exact file hashes. Commission candidates are labeled in `ART_CREDITS_TO_CONFIRM.csv`.
- One representative of visually similar versions was selected, and obvious sketches, working files (PSD/PDN/CLIP), video files, and alternate drafts were excluded.
- Collection entries not found in `Comms.zip` are **not automatically proven to be self-created**. Check ownership and artist names.
- Do not publish without confirming the right to display every piece, and adding accurate commission credits.
- The site references these files locally. There are no external tracking or image-hosting dependencies.
