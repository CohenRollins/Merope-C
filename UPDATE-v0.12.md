# Merope-C v0.12 — Anime Hub multi-source prototype

- Added seven external player candidates as a dropdown, plus existing Polaris and Jellyfin sources.
- Added on-demand iframe loading instead of loading third-party players while browsing.
- Added an AniMap MAL→TMDB/IMDb lookup endpoint to the existing media backend.
- Added season, episode, Sub/Dub selectors and an episode next/previous control.
- Added a manual metadata-ID correction form for unreliable anime season matching.
- Preserved local library streaming and custom playback links.
- No scraped videos, access-control circumvention, or copyrighted downloads included.

Read `ANIME-PROVIDERS-START-HERE.md` for installation and known limitations.
